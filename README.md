# games.gradedprompts.com

The index page of the playable demos for Graded Prompts' app and game prompts: https://games.gradedprompts.com/

Each demo lives in its own repository under this account and is served at `https://games.gradedprompts.com/<repository>/`. This repository holds only the index, its thumbnails, `robots.txt`, `sitemap.xml` and the 404 page.

Browse the prompts: https://www.gradedprompts.com/prompts/apps
